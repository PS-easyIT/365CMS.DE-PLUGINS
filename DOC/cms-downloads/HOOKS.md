# Hooks – CMS Downloads

## Registrierte Actions

- `cms_init` → Installation/Migration prüfen
- `plugin_activated` → Tabellen und Seed-Daten anlegen
- `plugin_uninstalled` → Tabellen entfernen
- `cms_admin_menu` → Admin-Menü registrieren
- `register_routes` → Public-Routen registrieren
- `main_nav` → Navigationseintrag `Downloads`
- `head` → Public-CSS einbinden
