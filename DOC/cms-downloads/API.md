# API – CMS Downloads

## Klassen

### `CMS_Downloads`
Bootstrap-Klasse des Plugins.

### `CMS_Downloads_Installer`
Erstellt Tabellen, Seed-Daten und Versionseintrag.

### `CMS_Downloads_Repository`
CRUD für Downloads, Kategorien und Einstellungen.

### `CMS_Downloads_Public_Controller`
Öffentliche Archiv- und Download-Routen.

### `CMS_Downloads_Admin_Menu`
Registriert Admin-Menüs.

### `CMS_Downloads_Admin_Pages`
Rendert Dashboard, Downloads, Kategorien und Einstellungen.
