# CMS Organigramm – Changelog

## [0.1.0] – In Entwicklung

### Geplant / In Arbeit

- Plugin-Grundgerüst mit Singleton-Pattern
- Namespace `CMS365\Plugins\Organigramm`
- Datenbank: `cms_organigramm_charts`, `cms_organigramm_nodes`
- Admin-Backend: 5x5-Tab-Menüstruktur
- Visual Builder: Vanilla JS + Inline-SVG Canvas
- Node-Typen: Company, Expert, Job Profile, Custom
- Cross-Plugin-Integration: cms-companies, cms-experts, cms-jobprofile-generator
- Drag & Drop (Native HTML5 API)
- Zoom & Pan via CSS transform
- Export: PNG / SVG / PDF
- Shortcode: `[cms_organigramm]`
- Einbettung in Member-Pages
- Subscription-Integration: `limit_organigramms`, `limit_organigramm_nodes`
