# CMS Knowledgebase

## Überblick

`cms-knowledgebase` ergänzt 365CMS um eine kleine Wissensdatenbank mit automatischer interner Verlinkung, Tooltip-Vorschau und öffentlichen Seiten unter `/kb`.

## Kernfunktionen

- Admin-CRUD für Einträge
- Fokusbegriffe und Synonyme
- Auto-Linking via `content_render`
- Optionaler Output-Buffer-Fallback
- Öffentliche Archiv- und Detailseiten
- PSR-3-kompatibles Logging über den vorhandenen CMS-Logger
