# Changelog – CMS M365 Adminsites

## 1.0.1 – 2026-05-30

- Admin-CSRF-Fallback auf fail-closed gehärtet, falls `CMS\Security` nicht verfügbar ist.
- JSON-Ausgabe im Löschdialog robust gegen Encoding-Fehler abgesichert.

- Initiales Plugin erstellt.
- Kategorien, Portal-Tabelle und Einstellungs-Tabelle angelegt.
- Seed-Daten aus Nutzerliste und Webrecherche ergänzt.
- Adminbereich mit Portalen, Texten, Designoptionen und Hinweisen umgesetzt.
- Public-Seite mit Such-, Filter-, Karten- und Tabellenansicht erstellt.
- PHINIT-Sidebar-Widget vorbereitet.
- Dokumentation für README, Datenbank, Hooks, API und Changelog ergänzt.
