# CMS M365 Azure

`cms-m365azure` ist ein eigenständiges 365CMS-Plugin für eine öffentliche Übersicht der Microsoft-Azure-Dienste.

## Ziel

Azure Services sollen nach und nach redaktionell vorgestellt werden. Jede Kategorie erscheint im Inhaltsverzeichnis und enthält beliebig viele Service-Cards.

## Öffentliche Ausgabe

Standardroute: `/azure-services`

Die Ausgabe enthält:

1. optionalen Headerbereich
2. Inhaltsverzeichnis mit Kategorie-Ankern
3. Kategorieabschnitte
4. responsive Service-Cards

## Administration

Im Adminbereich können gesteuert werden:

- Slug, Titel, Overline, Einleitung und SEO-Texte
- Anzeige von Header, Inhaltsverzeichnis, Kategorie-Intro, Bildern, Links, Features und Use Cases
- Card-Bildposition und Bildbreite
- maximale Inhaltsbreite
- Farben und Card-Radius
- Kategorien und Services inklusive Sortierung und Aktivstatus
