# Feature Ideas for CMS Speakers

## 1) Advanced Multi-Criteria Speaker Search
- **Feature name:** Advanced Multi-Criteria Speaker Search
- **Short description:** Add optional filters for budget range, speaking format, verified rating, and event type, with saved filter presets for editors.
- **Why it fits this plugin:** The plugin already stores rich speaker metadata; better discovery would make existing data more useful for admins and planners.
- **Rough effort:** medium
- **Source link(s):**
  - https://speak-up.pro/en/explore-speakers
  - https://www.espeakers.com/
  - https://www.talkmezzo.com/for/event-planners

## 2) Speaker Availability Calendar Sync
- **Feature name:** Speaker Availability Calendar Sync
- **Short description:** Add per-speaker availability blocks and optional iCal export/import to reduce double bookings.
- **Why it fits this plugin:** The plugin already tracks events and availability status; a calendar layer would improve scheduling reliability.
- **Rough effort:** medium
- **Source link(s):**
  - https://www.espeakers.com/
  - https://www.cvent.com/en/event-management-software/speaker-management-software
  - https://sessionize.com/features

## 3) Event Call / Application Mode
- **Feature name:** Event Call / Application Mode
- **Short description:** Let admins publish an event request where speakers can apply with existing profiles and topic proposals.
- **Why it fits this plugin:** Extends the current directory from passive listing to active speaker sourcing without changing existing profile workflows.
- **Rough effort:** high
- **Source link(s):**
  - https://speak-up.pro/en/for-organizers
  - https://sessionize.com/features
  - https://docs.pretalx.org/

## 4) Speaker Document Portal
- **Feature name:** Speaker Document Portal
- **Short description:** Add a speaker upload area for headshots, slides, and speaker one-pagers with admin checklist status.
- **Why it fits this plugin:** The plugin already stores event appearances; a document portal would support real event operations before go-live.
- **Rough effort:** medium
- **Source link(s):**
  - https://www.cvent.com/en/event-management-software/speaker-management-software
  - https://www.swapcard.com/platform/integrations/sessionboard
  - https://sessionize.com/features

## 5) Structured Speaker Review and Rating
- **Feature name:** Structured Speaker Review and Rating
- **Short description:** Add optional private post-event ratings (content quality, delivery, audience fit) visible only to admins/editors.
- **Why it fits this plugin:** Helps improve future speaker selection and turns historical appearances into actionable quality signals.
- **Rough effort:** medium
- **Source link(s):**
  - https://www.talkmezzo.com/for/event-planners
  - https://speak-up.pro/en/explore-speakers
  - https://www.keynote.direct/

## 6) Speaker Profile Completeness Score
- **Feature name:** Speaker Profile Completeness Score
- **Short description:** Show an internal completeness meter (bio, topics, media, socials, events) and highlight missing required fields.
- **Why it fits this plugin:** Improves data quality with minimal UX disruption and leverages fields that already exist in the current schema.
- **Rough effort:** low
- **Source link(s):**
  - https://sessionize.com/for-speakers
  - https://sessionize.com/playbook/speaker-dashboard
  - https://github.com/pretalx/pretalx
